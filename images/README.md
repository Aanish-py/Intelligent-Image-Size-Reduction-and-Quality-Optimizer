# images/

Place your input images in this folder for compression.

**Supported formats:** `.jpg`, `.jpeg`, `.png`, `.bmp`, `.tiff`, `.tif`

A sample image (`sample.bmp`) is included for testing and demonstration.

## Usage Notes
- The program reads image files directly from disk with full validation.
- Real photographs compress significantly with JPEG (lossy) encoding.
- Lossless PNG encoding preserves exact pixel data.
